# Fuzzy Music

ВУЗовский проект по ВПД (введение в профессиональную деятельность).

Музыкальный плеер для Windows и Linux. Цель — поиск и потоковое прослушивание доступных публичных треков SoundCloud в собственном интерфейсе без ручного получения API-ключа пользователем.

Сейчас реализован самостоятельный Rust-модуль проверки SoundCloud. Он умеет искать публичные треки и получать доступный аудиопоток. Графический интерфейс для проверки не нужен.

## Стек и технологии

| Технология | Назначение | Состояние |
|---|---|---|
| Rust | Основная логика, интеграция SoundCloud и управление запросами | Используется |
| yt-dlp | Поиск, получение метаданных и доступных аудиопотоков | Используется |
| Cargo, rustfmt, Clippy | Сборка, тестирование, форматирование и проверка Rust-кода | Используются |
| Git и GitHub | Контроль версий, ветки и проверка изменений через Pull Request | Используются |
| Tauri 2 | Настольное приложение и связь интерфейса с Rust-ядром | Запланирован |
| React, TypeScript и CSS | Пользовательский интерфейс и оформление | Запланированы |
| mpv | Аудиодвижок для воспроизведения и управления звуком | Запланирован |
| SQLite | Локальное хранение избранного, плейлистов, истории и настроек | Запланирована |

## Архитектура

Приложение строится вокруг локального Rust-ядра. Планируемые модули:

- **Интерфейс:** поиск, результаты, медиатека и панель управления; взаимодействует с ядром через команды и события Tauri.
- **Интеграция SoundCloud:** поиск композиций, метаданные и получение актуального потока; базовая реализация находится в `crates/soundcloud`.
- **Воспроизведение:** управление аудиодвижком, очередью, позицией и громкостью.
- **Хранилище:** сохранение пользовательских данных в SQLite на компьютере пользователя.

Состав команды и распределение ролей: [docs/team.md](docs/team.md).

## Быстрый запуск на Windows x64

Необходимы Git, Rust stable и Microsoft C++ Build Tools с Windows SDK.

```powershell
.\scripts\check-soundcloud.ps1 -Query 'Молчат Дома' -Limit 3
```

При первом запуске скрипт скачает официальный yt-dlp в локальную папку tools и проверит SHA-256. SoundCloud-аккаунт, подписка и ручной API-ключ не требуются. Нужен доступ к SoundCloud и серверам загрузки зависимостей.

Ожидаемый результат: JSON со списком треков — названием, автором загрузки, продолжительностью, обложкой и ссылкой SoundCloud. Порядок и состав выдачи могут меняться.

```powershell
.\scripts\check-soundcloud.ps1 -Mode resolve -Query 'https://soundcloud.com/hephestosmusic/super-mario-world-game-over'
```

Команда resolve выводит сведения о доступном потоке. Она не запускает звук и не сохраняет полный трек.

Поиск и получение потока имеют общий тайм-аут 45 секунд. Его можно изменить, а отмену проверить отдельным параметром:

```powershell
.\scripts\check-soundcloud.ps1 -Query 'lofi hip hop' -TimeoutSeconds 1
.\scripts\check-soundcloud.ps1 -Query 'lofi hip hop' -CancelAfterSeconds 0.25
```

В этих примерах ожидаются сообщение timed out или cancelled и ненулевой код завершения. Отмена завершает процесс извлечения вместе с его дочерними процессами. Время первой сборки и загрузки инструментов не входит в тайм-аут запроса.
