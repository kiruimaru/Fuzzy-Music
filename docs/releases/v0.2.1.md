# Fuzzy Music 0.2.1

## Linux x86_64

Download **Fuzzy-Music-0.2.1-linux-x86_64.AppImage**, make it executable and open it:

```bash
chmod +x Fuzzy-Music-0.2.1-linux-x86_64.AppImage
./Fuzzy-Music-0.2.1-linux-x86_64.AppImage
```

The application shows missing playback dependencies on first launch. Select
**Install dependencies** to download pinned yt-dlp with SHA-256 verification into
your user data directory. To install missing mpv, select **Install system
packages (administrator approval)** first and approve the desktop password
dialog. Optional ffmpeg enables FLAC conversion. System installation supports
pacman, apt, dnf and zypper and requires a running polkit authentication agent.
Dependencies can also be checked from Settings. No download or privileged
installation starts without your action.

Without FUSE use `APPIMAGE_EXTRACT_AND_RUN=1` before the launch command.
For WebKit/Hyprland rendering issues use `WEBKIT_DISABLE_DMABUF_RENDERER=1`.
The AppImage is unsigned and targets x86_64 Linux with glibc 2.35 or newer;
not every distribution has been tested.

## Changes

- Dedicated album presentation, custom and animated backgrounds, frosted shell.
- Track radio with an extending related-track queue.
- Playback cache pinning and recovery improvements.
- Separate debug library data and actionable newer-schema errors.
- In-app Linux dependency setup and automatic GitHub AppImage builds.
- Windows-specific Clippy correction found during the unpublished 0.2.0 build.
- Elevated package installs have a root-owned timeout; cancellation cannot
  indefinitely block the UI waiting for a privileged child.

## Windows x64

Download **Fuzzy-Music-0.2.1-windows-x64.zip**, extract it, then run the included
`setup-windows-runtime.ps1` once before opening `Fuzzy Music.exe`.
WebView2 and optional ffmpeg remain separate prerequisites.

## Verification And Source

Assets have SHA-256 sidecars. The corresponding-source ZIP contains the exact
application and locked Rust/frontend sources; the Linux packaging-source archive
adds bundling scripts, system copyright notices and source-package coordinates.
Keep these available when redistributing. Media tools are acquired separately
from upstream or your distribution, not redistributed inside the AppImage.
Public SoundCloud availability and formats can change; download only audio
you have permission to retain. Human listening and broad clean-machine
acceptance are not established by automated startup tests.
